# Manual Testing Guide

## 1. Как поднять API локально
* **Порт:** 8080
* **Окружение (env):**
* **Тестовые данные:** Для тестов используются скрипты `rega.py`, `http-test.py`, `cancel.py`, `skip-jail.py`.
* **Очистка БД:** Чтобы сбросить базу данных перед тестом, запустите скрипт `dump_db.py` `
## 2. Что проверять всегда
1. **Формат envelope:** Убедиться, что API возвращает данные правильно  (например, JSON содержит поля `data`, `status`, `error`).
2. **Коды ошибок:** При неверных запросах должен возвращаться корректный HTTP статус (400, 401, 404, 500 и т.д.), а не просто 200 OK с текстом ошибки.
3. **Язык сообщений:** Сообщения об ошибках и ответы должны соответствовать ожидаемой локализации (языку).

## 4. Правила репорта багов
Если во время прогона найден баг:
1. Заводим новую Issue в репозитории проекта.
2. Обязательно вешаем метку (label) `bug`.
3. В описании бага **обязательно** даем ссылку на конкретный шаг из тест-кейса, на котором произошла ошибка (и прикладываем фактический результат).
